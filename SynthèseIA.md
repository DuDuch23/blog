# Utilisation de l'ia

## Pourquoi je l'ai utilisé
Je ne l'ai pas utilisé au début pour voir ce que j'avais compris et ce que j'étais capable de faire après l'aprentissage de nextjs. Je l'ai ensuite utilisé lorsque je voulais peaufiner du code, m'aider à faire du code redondant, me conseiller sur quoi utilisé comme plugin (comme React Qwuill pour le bloc wysiwyg).

## J'ai utilisé l'ia pour:
- lorsque je suivais une doc et qui manquait quelque chose
- corriger des bugs
- configurer le docker
- du style
- si une fonctionnalité était redondante à faire
- m'aider à comprendre prisma lorsque la doc ne m'aidait pas
- un jeu de donnée
- me dire et m'expliquer pourquoi si il y a des erreurs
- corriger et analyser mon code
- me générer le squelette d'une page

## Ce que j'ai compris
- J'ai appris plus que la docs de prisma
- Plus de connaissances acquises
- M'a aidé à comprendre mon code
- Qu'il faut bien apprendre son code
